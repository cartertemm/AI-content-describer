# Описувач вмісту за допомогою ШІ для NVDA

Цей додаток дозволяє отримати докладні описи для зображень, елементів керування інтерфейсу користувача та іншого візуально недоступного вмісту.

Використовуючи мультимодальні можливості передових моделей штучного інтелекту та алгоритмів комп'ютерного зору, ми прагнемо надавати найкращі у своєму класі описи контенту та підвищити загальну незалежність. Для отримання додаткової інформації про моделі, що лежать в основі, зверніться до відповідного розділу цього документа.

## Особливості

* Опис об'єкта у фокусі, об'єкта навігатора, всього екрана або фотографії з вбудованої камери
* Опис будь-якого зображення, яке було скопійовано до буфера обміну, чи то зображення з електронного листа, чи шлях у провіднику Windows
* Копіювання зображення об'єкта у фокусі, об'єкта навігатора або всього екрана до буфера обміну, щоб вставити його в інші програми
* Визначає, чи обличчя користувача розташоване в центрі кадру, використовуючи алгоритми комп'ютерного зору (не потребує доступу до платного API)
* Використання підтримуваних моделей для керування активною програмою за допомогою миші та клавіатури для виконання потенційно недоступних завдань
* Початково безкоштовно, за бажанням додайте свій API ключ для інших моделей
* Підтримує декілька провайдерів (GPT від OpenAI та безкоштовний тариф Pollinations, Gemini від Google, Mistral Large 4, Claude від Anthropic, Grok від xAI, Kimi від Moonshot AI, vivo BlueLM Vision через NVDA-CN, Datalab Chandra 2, Ollama, llama.cpp, LiteLLM Proxy та Seer)
* Підтримує широкий спектр форматів, включаючи PNG (.png), JPEG (.jpeg і .jpg), WEBP (.webp) і неанімований GIF (.gif)
* Додатково кешує відповіді, щоб зберегти ліміт API
* Для розширеного використання налаштуйте підказку та кількість токенів, щоб адаптувати інформацію до ваших потреб
* Ставте уточнюючі запитання та додавайте додаткові зображення
* Відтворення Markdown для легкого доступу до структурованої інформації (просто увімкніть налаштування «відкривати результат у діалозі, доступному для огляду» і вставте, наприклад, «відповідай в Markdown» у кінці підказки)

## Варіант використання

За цим проєктом стояло кілька основних мотивів.

NVDA початково здатна виконувати оптичне розпізнавання символів (OCR), що змінює правила гри. Якщо ви намагаєтеся витягти текст із зображення або PDF-документа, це те, що вам потрібно.

Однак OCR здатний аналізувати лише ті дані, які *можуть* бути текстом. Він не здатен врахувати контекст, об'єкти та взаємозв'язки, передані в цих зображеннях. А в інтернеті їх повно. Логотипи, портрети, меми, іконки, графіки, діаграми, гістограми та лінійні графіки... Все, що завгодно. Вони всюди, і, як правило, не в тому форматі, який користувачі екранних читачів можуть інтерпретувати.
Донедавна доводилося цілковито покладатися на авторів вмісту, які надавали альтернативні текстові описи. Хоча це все ще є обов'язковим, важко змінити той факт, що високий стандарт якості є скоріше винятком, ніж правилом.

Тепер можливості майже безмежні. Ви можете:

* Візуалізувати робочий стіл або конкретне вікно, щоб зрозуміти розміщення іконок під час навчання інших
* Отримати детальну інформацію про стан ігор, віртуальних машин тощо, коли звук недостатній або недоступний
* Зрозуміти, що відображається на графіку
* Розібратися зі знімками екрана або демонстрацією екрана в Zoom чи Microsoft Teams
* Попросити модель, що підтримується, допомогти у використанні недоступної програми або виконати завдання у вікні на передньому плані
* Переконатись, що ваше обличчя чітко дивиться на камеру, а фон має професійний вигляд, перш ніж записувати відео або брати участь в онлайн-зустрічі

## Моделі

* [Pollinations](https://pollinations.ai/): Команда Pollinations.AI щедро надає безкоштовний доступ до GPT4 для цього проєкту, тому користувачам не потрібно вводити власний API-ключ. Зверніть увагу, що у роботі сервісу були виявлені помилки, тому ми настійно рекомендуємо використовувати власні ключі, щоб повною мірою скористатися перевагами цього проєкту.
* [Моделі OpenAI GPT](https://platform.openai.com/docs/models): Потрібен ключ API OpenAI. Включає сімейство GPT-5.4 (5.4 та 5.4 mini), сімейство GPT-5.5 (5.5 та 5.5 pro), сімейство GPT-6 (6 Astra та 6 Luna) і сімейство GPT-6.1 (6.1 Sol та 6.1 Terra). Керування комп'ютером підтримують сімейства GPT-5.4, GPT-5.5, GPT-6 та GPT-6.1.
* [Google Gemini](https://deepmind.google/models/gemini/), включаючи моделі 2.5 Flash, 2.5 Flash-Lite, 2.5 Pro, 3.1 Flash-Lite, 3.1 Pro Preview, 3.5 Flash, 3.5 Flash-Lite, 3.6 Flash, 3.7 Flash, 3.8 Flash, 4 Hydrogen, 4 Argon та 4 Carbon.
* [Anthropic Claude](https://docs.anthropic.com/claude/docs/vision), зокрема Claude 4.5 (Sonnet, Opus), 4.6 (Sonnet, Opus), 4.7 Opus, 4.8 Opus, 5 (Sonnet, Opus, Fable), 5.1 Fable, 5.2 Fable та 5.5 (Haiku, Sonnet, Opus). Усі вони підтримують керування комп'ютером.
* [Mistral Large 4](https://docs.mistral.ai/models/mistral-large-4-0)
* [xAI Grok](https://docs.x.ai/developers/models), зокрема Grok 4.20 (без міркувань), 4.3, 4.5, 4.6 та 4.7.
* [Kimi](https://platform.kimi.ai/docs/guide/use-kimi-vision-model), мультимодальні моделі Moonshot AI, зокрема Kimi K3 та Kimi K2.6.
* vivo BlueLM Vision: мультимодальна модель від vivo, доступ до якої можна отримати через безкоштовний обліковий запис NVDA-CN. Дивіться розділ налаштування нижче.
* [Datalab Chandra 2](https://github.com/datalab-to/chandra): Сучасна модель комп'ютерного зору та OCR від Datalab, що спеціалізується на складній верстці документів, таблицях, формах, рукописному тексті, діаграмах і математиці. Підтримує керований хмарний API Datalab (на [datalab.to](https://www.datalab.to)) або власне розгортання через vLLM (за допомогою `chandra_vllm` або OpenAI-сумісних кінцевих точок `/v1`).
* [Ollama (нестабільна)](https://ollama.com/)
* [llama.cpp (дуже нестабільна та повільна залежно від вашого обладнання, перевірена на сумісність з моделями llava-v1.5/1.6, BakLLaVA, Obsidian та MobileVLM 1.7B/3B)](https://github.com/ggerganov/llama.cpp)
* [LiteLLM Proxy](https://docs.litellm.ai/docs/proxy/quick_start): Доступ до декількох моделей ШІ через єдиний проксі-сервер. Потрібна URL-адреса проксі-сервера LiteLLM, а також, за потреби, ключ API, залежно від налаштувань вашого проксі. У діалозі налаштувань моделі відображається як «LiteLLM Proxy». Підтримує динамічний вибір моделі та додаткові запитання. Сумісний з усіма форматами (PNG, JPEG, WEBP, GIF).
* [Seer](https://github.com/recursia-lab/Seer): Запускає PaliGemma2 локально через демон Seer. Не потрібен API-ключ або підключення до Інтернету. Примітка: це модель, призначена виключно для створення підписів. Підказки та додаткові запитання не підтримуються.

Дотримуйтеся наведених нижче інструкцій, щоб кожна з них працювала.

## Початок роботи

Завантажте останню версію додатка за [цим посиланням](https://github.com/cartertemm/AI-content-describer/releases/latest/). Клацніть файл на комп'ютері з інстальованою NVDA та виконайте встановлення, дотримуючись підказок.

Під час першого запуску NVDA з додатком буде запропоновано завантажити кілька додаткових бібліотек. Докладніше дивіться в розділі `Залежності` цього документа.

Починаючи з версії 2025.06.05, використання GPT4 є безкоштовним завдяки щедрості спільноти, що стоїть за PollinationsAI.

Якщо у вас є ресурси та інтерес до вивчення додаткових моделей, ви завжди можете використати власний ключ API і зменшити кількість запитів до їхніх серверів. Якщо ви цього не зробите, просто перейдіть до розділу `Використання` в цьому документі.

Дотримуйтесь наведених нижче інструкцій, щоб отримати ключ API від підтримуваного постачальника.

### Яку модель використовувати?

Раніше ми надавали рекомендації щодо найдешевших і найякісніших варіантів, але ситуація змінюється настільки стрімко, що неможливо встигати за цими змінами.

Коротка відповідь така: більшість сучасних моделей досягли рівня, коли вони забезпечують достатню точність для більшості повсякденних завдань, тому обирайте того постачальника, з яким ви вже знайомі.

Більшість людей хочуть знайти баланс між точністю та вартістю. [Таблиця лідерів LLM arena](https://lmarena.ai/leaderboard) (зокрема категорія візуальних моделей) вимірює правильність, а [калькулятор цін на LLM](https://www.llm-prices.com/) показує ціни.

Якщо ви хочете використовувати керування комп'ютером, виберіть одну з підтримуваних моделей OpenAI або Anthropic, перелічених вище. Безкоштовний доступ через Pollinations корисний для опису зображень, але не підтримує керування комп'ютером.

### Отримання ключа API від OpenAI:

1. Перейдіть на [сторінку ключів API OpenAI](https://platform.openai.com/account/api-keys)
2. Якщо у вас ще немає облікового запису, створіть його. Якщо маєте, увійдіть.
3. На сторінці ключів API натисніть «Створити новий секретний ключ». Скопіюйте його в буфер обміну.
4. Поповніть рахунок принаймні на 1 дол.
5. У діалозі налаштувань NVDA прокрутіть вниз до категорії «Описувач вмісту за допомогою ШІ», потім виберіть "керувати моделями (alt+m)", виберіть будь-яку з моделей OpenAI (наприклад, «GPT-6.1 Sol») як постачальника, перейдіть до поля «Ключ API» і вставте туди щойно згенерований ключ.

На момент написання цієї статті OpenAI видає кредити на нові акаунти розробників, які можна використовувати протягом трьох місяців, після чого вони втрачаються. Після цього періоду вам потрібно буде придбати кредити. Звичайне використання не повинно перевищувати $5.00 на місяць. Для порівняння, оригінальна версія цього додатка була розроблена за трохи менше долара. Ви завжди можете увійти до свого облікового запису OpenAI і натиснути на "використання", щоб дізнатись свій ліміт.

### Отримання ключа API від Google

1. Спочатку вам потрібно створити проєкт у робочому просторі Google у [консолі Google Cloud](https://console.cloud.google.com/projectcreate). Переконайтеся, що ви увійшли до свого облікового запису Google.
2. Створіть назву від чотирьох до тридцяти символів, як-от «Gemini» або «NVDA add-on»
3. Перейдіть на [сторінку ключів API Google AI Studio](https://makersuite.google.com/app/apikey)
4. Натисніть «створити ключ API»
5. У діалозі налаштувань NVDA прокрутіть вниз до категорії Описувач вмісту за допомогою ШІ, потім виберіть "керувати моделями (alt+m)", виберіть "Google Gemini" як постачальника, перейдіть до поля "Ключ API" і вставте сюди щойно згенерований ключ.

### Отримання ключа API від Anthropic

1. Увійдіть до [консолі Anthropic](https://console.anthropic.com/login).
2. Натисніть на свій профіль -> Ключі API.
3. Натисніть Створити ключ.
4. Введіть назву для ключа, наприклад "AIContentDescriber", потім натисніть "Створити ключ" і скопіюйте значення, що з'явиться. Це те, що ви вставите у поле ключа API під категорією Описувач вмісту за допомогою ШІ діалогу налаштувань NVDA -> керувати моделями -> будь-яка модель Claude (наприклад, «Claude 5 Sonnet»).
5. Якщо ви ще цього не зробили, придбайте кредитів щонайменше на 5 доларів США на [сторінці планів Anthropic](https://console.anthropic.com/settings/plans).

### Отримання ключа API від Mistral

1. Увійдіть або створіть обліковий запис MistralAI, перейшовши на [сторінку входу в MistralAI](https://auth.mistral.ai/ui/login).
2. Якщо ви створюєте обліковий запис або входите в нього вперше, додайте робочу область відповідно до запиту, вказавши ім'я та прийнявши умови та положення.
3. Після входу в систему виберіть «API ключі» з меню.
4. Натисніть «створити новий ключ» і скопіюйте його в буфер обміну. Це значення буде вставлено у поле «Ключ API» в категорії «Описувач вмісту за допомогою ШІ» у діалозі налаштувань NVDA -> Керування моделями -> Mistral Large 4.
5. Поповніть рахунок, якщо це необхідно.

### Отримання ключа API від Kimi (Moonshot AI)

1. Увійдіть або створіть обліковий запис на [платформі для розробників Kimi](https://platform.kimi.ai/).
2. Після входу в систему відкрийте розділ ключів API у консолі та створіть новий ключ.
3. Скопіюйте ключ у буфер обміну. Це значення буде вставлено у поле «Ключ API» в категорії «Описувач вмісту за допомогою ШІ» у діалозі налаштувань NVDA -> Керування моделями -> Kimi K3 (або інша модель Kimi).
4. Поповніть рахунок, якщо це необхідно.


### Активація моделі розпізнавання VIVO BlueLM через NVDA-CN

Ця послуга надається безкоштовно завдяки партнерству між компанією VIVO (vivo.com.cn) та китайською спільнотою NVDA (NVDACN). Вона забезпечує високоякісне мультимодальне розпізнавання і є рекомендованою моделлю для всіх користувачів, особливо для початківців.

Щоб скористатися цією моделлю, вам знадобиться лише безкоштовний обліковий запис NVDA-CN.

1.  Створіть обліковий запис: перейдіть на сторінку реєстрації NVDA-CN: [https://nvdacn.com/admin/register.php](https://nvdacn.com/admin/register.php).
    * **Примітка**: Наразі сторінка доступна лише китайською мовою. Для заповнення форми рекомендуємо скористатися вбудованою функцією перекладу вашого браузера.
    * Вам буде запропоновано ввести ім'я користувача, пароль та дійсну адресу електронної пошти. Обов'язково збережіть свій пароль у безпечному місці, оскільки автоматичне відновлення пароля ще не реалізовано.
2.  Підтвердьте свою електронну пошту: Перевірте свою поштову скриньку на наявність листа з підтвердженням та натисніть на посилання в ньому, щоб активувати свій обліковий запис.
3.  Налаштуйте додаток:
    * Відкрийте діалог налаштувань NVDA та перейдіть до категорії «Описувач вмісту за допомогою ШІ».
    * Натисніть кнопку «Керувати моделями».
    * У списку постачальників виберіть «vivo BlueLM Vision (NVDA-CN)».
    * Введіть своє ім'я користувача та пароль NVDA-CN у відповідні поля.
    * Натисніть «OK», щоб зберегти свої облікові дані.

Тепер ви готові до використання моделі VIVO. З будь-яких питань, пов'язаних з обліковим записом, ви можете звернутися до команди NVDA-CN за адресою `support@nvdacn.com`.


### Налаштування Ollama

Наразі це найкращий варіант для локального налаштування.

Хоча інтеграція Ollama була протестована більш широко, ніж llama.cpp, вона все ще менш стабільна, ніж виклик API, і, як відомо, поводиться дивно в деяких конфігураціях, аж до збоїв на комп'ютерах, які не мають необхідних характеристик.
Щонайменше, коли пробуєте це вперше, збережіть усі документи та важливі дані перед тим, як продовжити, щоб бути готовими у випадку, якщо це станеться з вами.

Почніть з перевірки можливості взаємодії з вашою моделлю, здатною до комп'ютерного зору, використовуючи інтерфейс командного рядка. Кроки для цього такі:

1. Завантажте інсталяційний файл Ollama для Windows зі сторінки [Завантаження Ollama](https://ollama.com/download).
2. Запустіть цей файл налаштування. Він автоматично завантажить усі залежності, необхідні для вашого комп'ютера.
3. Знайдіть модель, яку ви хочете використовувати. Список можна знайти на ollama.com -> models -> vision, або [безпосередньо тут](https://ollama.com/search?c=vision).
4. Завантажте і запустіть цю модель, відкривши командний рядок і набравши `ollama run [model_name]`, звичайно, замінивши «[model_name]» на ту, яку ви вибрали на кроці 3. Наприклад, `ollama run llama3.2-vision`.
5. Якщо процес завершився успішно, ви потрапите в інтерактивну оболонку, де зможете вводити запити та отримувати відповіді від моделі, подібно до локалізованого (та обмеженого) ChatGPT. Перевірте це, задавши будь-яке питання, щоб перевірити, чи працює воно, а потім введіть "/bye", щоб вийти з цього інтерфейсу.
6. Повернувшись до вікна консолі, введіть `ollama list`. У першому стовпчику буде вказано назву на зразок «llama3.2-vision:latest».
7. Перейдіть до налаштувань Описувач вмісту за допомогою ШІ -> керувати моделями -> Ollama. У полі «Назва моделі» введіть це значення і натисніть «ОК» -> «ОК». Все готово! Перейдіть на Ollama в підменю моделі, і через деякий час вона має запрацювати.

### Налаштування llama.cpp

Наразі цей провайдер є дещо нестабільним, і ваш досвід може значно варіюватися. Насправді його варто використовувати лише досвідченим користувачам, які зацікавлені у використанні локальних саморозміщених моделей і мають для цього відповідне апаратне забезпечення.

1. Завантажте llama.cpp. На момент написання цієї статті цей [pull request](https://github.com/ggerganov/llama.cpp/pull/5882) вилучає мультимодальні можливості, тому вам краще використовувати [останню версію з підтримкою цього](https://github.com/ggerganov/llama.cpp/releases/tag/b2356).
Якщо ви працюєте на графічному адаптері Nvidia з підтримкою CUDA, завантажте ці готові двійкові файли:

Кроки для роботи з іншим графічним адаптером винесено за рамки цієї статті, але їх можна знайти у файлі readme llama.cpp.
2. Розпакуйте обидва файли до однієї теки.
3. Знайдіть у Huggingface квантовані формати моделей, які ви хочете використовувати. Для LLaVA 1.6 Vicuna 7B: [llava-v1.6-vicuna-7b.Q4_K_M.gguf](https://huggingface.co/cjpais/llava-v1.6-vicuna-7b-gguf/blob/main/llava-v1.6-vicuna-7b.Q4_K_M.gguf) та [mmproj-model-f16.gguf](https://huggingface.co/cjpais/llava-v1.6-vicuna-7b-gguf/blob/main/mmproj-model-f16.gguf)
4. Покладіть ці файли до теки з рештою двійкових файлів llama.cpp.

### Налаштування проксі-сервера LiteLLM

Проксі-сервер LiteLLM надає єдиний інтерфейс для доступу до декількох моделей штучного інтелекту через одну кінцеву точку, що спрощує управління моделями та дозволяє легко перемикатися між постачальниками.

1. Налаштуйте проксі-сервер LiteLLM, дотримуючись [документації проксі-сервера LiteLLM](https://docs.litellm.ai/docs/proxy/quick_start). Ви можете запустити проксі локально або використовувати віддалений сервер.
2. Якщо ви запускаєте локально, найшвидший спосіб розпочати роботу:
```
pip install 'litellm[proxy]'
litellm --model gpt-4o
```
Це запустить проксі-сервер за адресою `http://localhost:4000`, який переадресовує запити до GPT-4o від OpenAI.
3. Для використання у виробничому середовищі створіть файл `config.yaml`, щоб налаштувати кілька моделей та автентифікацію. Детальніше дивіться у [посібнику з налаштування LiteLLM](https://docs.litellm.ai/docs/proxy/configs).
4. У діалозі налаштувань NVDA прокрутіть вниз до категорії «Описувач вмісту за допомогою ШІ», потім виберіть "керувати моделями (alt+m)" і виберіть «LiteLLM Proxy» як свого постачальника.
5. Введіть URL вашого проксі-сервера в поле «базова URL» (наприклад, «http://localhost:4000» для локального або URL вашого віддаленого сервера).
6. Якщо ваш проксі вимагає автентифікації, введіть ключ API у поле Ключ API. Якщо ні, залиште його порожнім.
7. Натисніть кнопку «Список моделей», щоб завантажити доступні моделі з вашого проксі, а потім виберіть модель, яку ви хочете використовувати, зі списку.
8. Налаштуйте інші параметри, такі як підказка, максимальна кількість токенів та час очікування, за потреби, а потім натисніть OK.

Примітка: Доступні моделі та їхні можливості залежать від конфігурації вашого проксі-сервера LiteLLM. Переконайтеся, що ваш проксі-сервер налаштований з моделями, здатними обробляти зображення, для опису зображень.

### Налаштування Seer

Seer запускає PaliGemma2 на вашому комп'ютері без необхідності використання API-ключа чи підключення до хмари. Зверніть увагу, що ця модель призначена виключно для створення підписів; підказки та додаткові запитання не підтримуються.

1. Встановіть [демон Seer](https://github.com/recursia-lab/Seer). Для Windows (.bat) та Linux/macOS (.sh) надається інсталятор з однією командою.
2. У діалозі налаштувань NVDA перейдіть до категорії «Описувач вмісту за допомогою ШІ», виберіть «керувати моделями (alt+m)» та виберіть «Seer (потрібне встановлення)».
3. Базовий URL початково `http://127.0.0.1:11435`. Залиште його без змін, якщо ви не змінювали порт демона.
4. Натисніть «OK». Демон має працювати, перш ніж ви спробуєте отримати опис.

### Налаштування Datalab Chandra 2

Datalab Chandra 2 є сучасною моделлю для аналізу документів та OCR, що спеціалізується на складній верстці, таблицях, формах, рукописному тексті, діаграмах і математичних формулах. Її можна використовувати через керований хмарний API Datalab, локальний контейнер або власний екземпляр vLLM.

#### Варіант A: Хмарний API Datalab (рекомендовано)
1. Зареєструйтеся на [datalab.to](https://www.datalab.to). Нові облікові записи отримують безкоштовні пробні кредити.
2. Відкрийте [сторінку ключів API](https://www.datalab.to/app/keys) та створіть ключ API.
3. У діалозі налаштувань NVDA перейдіть до категорії «Описувач вмісту за допомогою ШІ», виберіть «керувати моделями (alt+m)» та виберіть «Datalab Chandra 2».
4. Введіть свій ключ API у поле «Ключ API».
5. Початково базова URL-адреса має значення `https://www.datalab.to/api/v1/convert`. Ви можете змінити режим обробки (`fast`, `balanced` або `accurate`) відповідно до своїх потреб.
6. Натисніть «OK». Модель стане доступною в меню Описувача вмісту за допомогою ШІ.

#### Варіант B: Власний сервер із vLLM
1. Запустіть локальний сервер vLLM із Chandra 2 (наприклад, за допомогою `chandra_vllm` або `vllm serve datalab-to/chandra-ocr-2`). Початково сервер працює за адресою `http://localhost:8000/v1`.
2. У налаштуваннях NVDA -> Описувач вмісту за допомогою ШІ -> Керувати моделями -> «Datalab Chandra 2» введіть адресу локальної кінцевої точки в поле «Базова URL-адреса» (наприклад, `http://localhost:8000/v1`).
3. Вкажіть назву моделі, якщо вона відрізняється від стандартної (`datalab-to/chandra-ocr-2`), залиште поле ключа API порожнім (або вкажіть bearer-токен, якщо ввімкнено автентифікацію) і натисніть «OK».

## Використання

Початково призначено шість гарячих клавіш:

* NVDA+shift+i: відкриває спливаюче меню із запитом, чи потрібно описати поточний фокус, об'єкт навігатора, фізичну камеру чи весь екран, або керувати комп'ютером за допомогою ШІ.
* NVDA+shift+u: Описати вміст поточного об'єкта навігатора за допомогою ШІ.
* NVDA+shift+y: Описати зображення (або шлях до файлу зображення) у буфері обміну за допомогою ШІ.
* NVDA+shift+j: описати положення вашого обличчя в кадрі вибраної камери. Якщо у вас під'єднано кілька камер, перейдіть до меню описувача вмісту за допомогою ШІ (NVDA+shift+i) і виберіть ту, яку ви бажаєте використати, за допомогою пункту «Виберіть камеру» у підменю визначення обличчя.
* NVDA+alt+c: відкрити діалог розмови з ШІ, щоб задати додаткові запитання.
* NVDA+control+shift+p: призупинити або відновити активний сеанс керування комп'ютером.

Сім жестів не призначені:

* Описати вміст об'єкта, на якому перебуває фокус, використовуючи ШІ.
* Зробити знімок екрана, а потім описати його за допомогою ШІ.
* Зробити знімок за допомогою вибраної камери, а потім описати його за допомогою ШІ.
* Скасувати активний сеанс керування комп'ютером.
* Зробити знімок поточного об'єкта у фокусі та скопіювати його до буфера обміну.
* Зробити знімок поточного об'єкта навігатора та скопіювати його до буфера обміну.
* Зробити знімок усього екрана та скопіювати його до буфера обміну.

Три команди копіювання також доступні в підменю «Копіювати зображення до буфера обміну» меню NVDA+shift+i. Вони нічого не надсилають до сервісу ШІ. Використовуйте їх, щоб вставити знімок у Be My AI або іншу програму, яку цей додаток не підтримує. Копіювання замінює попередній вміст буфера обміну.

Ви можете налаштувати їх у будь-який час за допомогою діалогу «Жести вводу».

### Подальші кроки щодо попереднього опису

Іноді відповідь, яку ви отримуєте від ШІ, буває недостатньою. Можливо, зображення низької якості, неповне або містить небажані деталі. Можливо, ви хочете зосередитися на певній ділянці або зробити чіткіше фото без втрати контексту.
Отримавши опис, ви можете натиснути NVDA+alt+c або вибрати «Подальші кроки щодо попереднього опису» у контекстному меню Описувач вмісту за допомогою ШІ (NVDA+shift+i). Початково фокус встановлюється на полі повідомлення.
Щоб додати додаткове зображення, просто тримайте діалог розмови відкритим і використовуйте додаток, як ви зазвичай робите. Коли буде зроблено знімок (будь то з камери, елемента керування системи, знімка екрана тощо), вас запитають, чи хочете ви прикріпити його до поточного сеансу чи почати новий.

### Керування комп'ютером

Функція «Керування комп'ютером» дозволяє Описувачу вмісту керувати активною програмою за допомогою миші та клавіатури після того, як ви опишете завдання. Це допомагає виконувати завдання, які важко або неможливо здійснити вручну.

Оскільки це надає ШІ-моделі керування вашим комп'ютером, використовуйте його обережно. Додаток запитує згоду перед початком, звітує про дії в реальному часі та запитує підтвердження перед виконанням потенційно небезпечних операцій. Ви несете відповідальність за його роботу, тому контролюйте сеанс і уникайте використання інструменту для конфіденційних завдань або операцій, які важко скасувати.

Ви можете у будь-який момент призупинити або відновити керування комп'ютером за допомогою комбінації клавіш `NVDA+Control+Shift+P`. Під час призупинення додаток не перейде до наступної дії, доки ви не відновите його роботу.

Цей додаток використовує звукові сигнали для позначення стану керування. Високий звуковий сигнал означає, що модель бере керування на себе або відновлює його. Низький звуковий сигнал означає, що керування призупинено, або через те, що ви його призупинили, або через те, що модель потребує введення даних. Короткий низький звуковий сигнал про помилку означає, що сеанс зупинився через помилку API.

Під час активного сеансу керування модель заздалегідь промовлятиме свої дії перед введенням даних. Нічого не відбудеться, поки мовлення не завершиться, якщо ви не натиснете `Control`, щоб перервати мовлення та прискорити виконання дії.

Якщо модель не знає, як виконати дію, потребує додаткової інформації або іншим чином передає хід вам, сеанс призупиняється і на передній план виходить діалог «Керування комп'ютером». Введіть там повідомлення, щоб продовжити розмову, або закрийте діалог, щоб завершити сеанс.

Ця функція працює лише з моделями, що підтримують інструмент керування комп'ютером: GPT-5.4, GPT-5.4 mini, GPT-5.5, GPT-5.5 pro, GPT-6 Astra, GPT-6.1 Sol, GPT-6.1 Terra, GPT-6 Luna, Claude 4.5 Sonnet, Claude 4.5 Opus, Claude 4.6 Sonnet, Claude 4.6 Opus, Claude 4.7 Opus, Claude 4.8 Opus, Claude 5 Sonnet, Claude 5 Opus, Claude 5 Fable, Claude 5.1 Fable, Claude 5.2 Fable, Claude 5.5 Haiku, Claude 5.5 Sonnet та Claude 5.5 Opus. Інші моделі можуть описувати зображення, але не надають структурованих команд для керування мишею та клавіатурою.

Щоб скористатися комп'ютерним керуванням:

1. Налаштуйте та виберіть одну з підтримуваних моделей.
2. Відкрийте програму або вікно, з яким має працювати модель.
3. Натисніть `NVDA+shift+i`, а потім виберіть «Керувати комп'ютером...».
4. Введіть завдання, яке потрібно виконати, і натисніть «Надіслати».
5. Ознайомтеся з запитом на згоду. Якщо ви дозволите сеанс, стежте за діями та затверджуйте або скасовуйте будь-які запити щодо ризикованих дій.

Примітка: Цю функцію слід розглядати як бета-версію, і ми активно працюємо над вдосконаленням її реалізації.

## Залежності

Деякі бібліотеки, потрібні цьому додатку, завеликі, щоб включати їх до пакета додатка. Натомість під час першого запуску NVDA зі встановленим додатком вас запитають, чи завантажити їх. Виберіть «Так», дочекайтеся завершення завантаження, і NVDA перезапуститься.

Завантажується zip-архів розміром приблизно від 35 до 70 МБ залежно від версії NVDA. Він береться зі сторінки [libs-release](https://github.com/cartertemm/AI-content-describer/releases/tag/libs-release) цього репозиторію. Якщо GitHub недоступний, додаток запропонує спробувати дзеркало, надане китайською спільнотою NVDA.

Архів містить:

* [NumPy](https://numpy.org/): математичні операції з масивами, потрібна для OpenCV.
* [OpenCV](https://opencv.org/) (`cv2`): знаходить ваше обличчя на зображеннях з вебкамери для функції визначення обличчя.
* [Pillow](https://python-pillow.org/) (`PIL`): робить знімки екрана та перетворює їх на зображення, які можуть прочитати моделі ШІ.
* [Markdown](https://python-markdown.github.io/): показує описи з форматуванням, наприклад заголовками, списками й таблицями.
* [pygrabber](https://github.com/andreaschiavinato/python_grabber): отримує список вебкамер на вашому комп'ютері.
* Кілька модулів стандартної бібліотеки Python, яких немає в NVDA (`html`, `xml`, `pathlib`, `secrets` та `_markupbase`). Вони потрібні бібліотекам, переліченим вище.

Файли розміщуються в теці з назвою `aic-py-` і версією Python, яку використовує NVDA, наприклад `aic-py-3.13`. Ця тека знаходиться в теці конфігурації користувача NVDA, зазвичай `%APPDATA%\nvda`. Для кожної версії Python створюється окрема тека, тому додаток знову завантажить бібліотеки, коли новий випуск NVDA змінить версію Python. Під час видалення додатка видаляється тека для поточної версії Python NVDA.

Якщо завантаження не працює, ви можете встановити бібліотеки самостійно. Завантажте `aic-py-3.13.zip` (або файл для версії Python вашої NVDA) зі сторінки libs-release, розпакуйте його в теку конфігурації користувача NVDA і перезапустіть NVDA.

## Збирання додатка

Щоб створити пакет додатка з вихідного коду, вам знадобиться:

* дистрибутив Python (рекомендовано версію 3.7 або новішу). Інсталятори для Windows можна знайти на [сайті Python](https://www.python.org). Зверніть увагу, що наразі для підготовки вихідного коду NVDA та включених до нього сторонніх модулів потрібна 32-бітна версія Python 3.7.
* Scons - [Сайт](https://www.scons.org/) - версія 4.3.0 або новіша. Ви можете встановити його через PIP. `pip install scons`
* Markdown 3.3.0 або новіша. `pip install markdown`

Потім відкрийте термінал на свій вибір:

```
git clone https://github.com/cartertemm/AI-content-describer.git
cd AI-content-describer
scons
```

Після завершення виконання команди `scons` у корені цього репозиторію з'явиться файл *.nvda-addon, готовий до тестування та випуску.

Якщо ви додаєте нові рядки, які потрібно перекласти, важливо перебудувати файл .pot таким чином:

```
scons pot
```

## Як перекласти?

На комп'ютері з Windows:

* завантажте [poedit](https://poedit.net/). Це програма, за допомогою якої ви перекладатимете кожне повідомлення з англійської.
* завантажте файл .pot з усіма рядками [тут](https://raw.githubusercontent.com/cartertemm/AI-content-describer/main/AIContentDescriber.pot)
* Відкрийте щойно завантажений файл у програмі poedit. У вікні, що з'явиться, натисніть «Створити новий переклад», а потім виберіть цільову мову.
* Перекладіть вміст вихідного тексту цільовою мовою та вставте його в поле перекладу. Для додаткової допомоги клацніть правою кнопкою миші на елементі списку -> входження в коді, потім перейдіть на рядок вище й прочитайте коментар, що починається з "# Translators: ". Ці коментарі також зібрано в одному місці у файлі .pot.
* Коли закінчите, натисніть файл -> зберегти або натисніть ctrl+s, а потім виберіть місце для збереження нових файлів .mo та .po. Саме ці файли слід надіслати мені електронною поштою або додати до pull request.
* Перекладіть вміст readme.md (цього файлу). Додайте і його!
